# TBL2 Astro Slides POC

Présentation TBL2 **100 % web** basée sur Astro Slides.

## Local development

```bash
pnpm install
pnpm dev
```

Le deck principal est dans `slides.mdx`. Les composants visuels animés sont dans `components/`.

## Build

```bash
pnpm build
```

Le projet est prévu pour être déployé directement sur Vercel.
